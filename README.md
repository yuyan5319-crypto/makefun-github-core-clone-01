A single-file, dependency-free GitHub-compatible git forge in TypeScript for Node 22: a real git smart-HTTP server (protocol v0 and v2, pack read/write with delta resolution), a REST v3 surface for repositories, issues, pull requests, labels and comments, a GraphQL v4 API with its own parser and executor, and an MCP server — all in memory, on a deterministic clock, zero dependencies.

## Run it

```sh
node main.ts
```
